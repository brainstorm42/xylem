# Supported Xylem examples

CompactBounds provides a complete five-binder statement projection, graph containment, and explanations of the leading compactness and positivity facts. Its premise records are unavailable. The Ctrllib example provides selected premise relationships, bounded dependency navigation, and a mathematical point-mass explanation. Its compact capture is partial.

Both examples use the packaged canonical CLI/MCP and statement converter. Notation rendering retains exact text where necessary and keeps formal acceptance unassessed. See [combined technical limits](../RELEASE-SCOPE.md), [CompactBounds first use](README.md), and [Ctrllib first use](examples/ctrllib-e2e/README.md).
